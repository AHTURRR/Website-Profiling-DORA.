# DORA website direction

Reference: Outcrowd, Website for an Incident Management Platform, https://dribbble.com/shots/26742281-Website-for-an-Incident-Management-Platform . Use its centered composition, generous space, near-black surfaces, violet accent, and large application preview as direction. All displayed product screenshots belong to DORA; do not reuse the reference product or its claims.

Identity: research software by Metriks Studio. Curious, precise, collaborative. Indonesian interface, short benefit-led headings, technical detail progressively disclosed.

ENERGY 3 / RHYTHM 3 / MOTION 3 (three-point scale). Strong centered hero with interactive four-view product stage and five-step conceptual research flow; asymmetric feature, workflow, add-ons empty/editorial state, and repository sections; restrained team grid. One typographic focal point per section. Both dark and light modes are intentionally crafted and stored in `dora-theme`.

Palette: dark uses near-black #08090d, surface #111218, text #f4f3f8, secondary #aaa9b8, violet #9e91ff, primary #6854df. Light uses paper #f7f6fb, white surface, text #22202e, secondary #5a5468, violet #5e3fb8, primary #6244ca. Violet identifies actions, active workflow steps, and section emphasis in both themes. Dark remains the reference-led default; the explicit user selection is stored under `dora-theme` and applied before styles load.

Hero & Product Stage: the hero centers a dominant HTML/CSS desktop window frame displaying real DORA v6.0.0 screenshots (`overview.png`, `dataset-preview.png`, `node-editor.png`, `academic-research.png`). A centered showcase control cluster (`.hero-view-pill-cluster`) houses a live telemetry status beacon and 4 numbered view tabs (`01 Overview`, `02 Dataset`, `03 Node Editor`, `04 Research`), eliminating unbalanced void gaps. The desktop frame features macOS-style traffic light window controls, app mark, version pill, active stage badge, and an expand button opening the full screenshot in a native `<dialog>`. Switching views activates an animated laser scan sweep (`.hero-scan-beam`) across the screenshot viewport. Directly below the hero, a five-step conceptual workflow strip (`Memuat data` -> `Memahami data` -> `Merangkai eksperimen` -> `Menelusuri literatur` -> `Menyusun hasil`) is explicitly labeled as a conceptual illustration and synchronizes with the hero mockup views on click or tap.

Lighting & Glass Cap: the hero ambient lighting scene uses a balanced, centered radial aura (`.hero-light`) positioned symmetrically behind the headline and window frame, replacing the legacy diagonal streak to prevent cutoffs and visual obstruction. The scene is augmented with dual concentric SVG telemetry reticles and peripheral floating HUD data tags (`ENGINE: AIRGAPPED LOCAL`, `RUNTIME: PYTORCH · SKLEARN`, `GRAPH: REACTIVE PIPELINE`, `PRIVACY: ZERO-TELEMETRY`). The floating rounded navigation uses backdrop blur, preserving readability over scrolling content. No global glass cards or glowing icons.

Typography: retain Plus Jakarta Sans, whose rounded forms suit the DORA wordmark and human research context. JetBrains Mono is limited to filenames, commands, step indices, compatibility tags, and hashes. Headings use regular/medium weight, compact tracking, balanced lines. Body copy remains at least 14px.

Motion & Motion Graphics: CSS ambient light drifts at 16s and light points at 12s, with a slow 48s orbital telemetry reticle in the hero background. The hero intro brings focus from headline to the product stage via staggered fade-up. Below fold, elements use 550ms Web Animations on intersection. In the Visual Node Editor section, an SVG pipeline topology banner renders animated traveling laser pulses (`wire-laser` at 1.5-1.8s) between connected data and model nodes. The Preview section (`#preview`) is transformed into a Cybernetic Motion Graphic Theater featuring an interactive category ribbon, corner reticles (`[HUD // CAM]`), dynamic laser scanline sweep (`laser-scanline` 1.4s), live stream beacon, thumbnail track, and smooth progress tracking. On `/tim`, each member card features a rotating gyroscopic vector graphic (`member-gyro` at 36s) behind the monogram. All continuous motion graphics are hardware-accelerated (`transform`, `opacity`, `stroke-dashoffset`) and automatically disabled under `prefers-reduced-motion: reduce`. Content remains fully readable without JS.

Controls & Standardized Radius System: Floating navbar uses a unified 64px height with pixel-perfect vertical centering, pairing a direct DORA Web (Beta) link (`https://data-overview-research-and-assistant.netlify.app`), ThemeToggle, and primary download CTA at an identical 40px height. To eliminate off-site navigation fragmentation, external GitHub repository links are strictly consolidated and confined into the dedicated `#addons` and `#github` sections. Border radii strictly adhere to a 3-tier hierarchy: `--radius-pill` (9999px) for interactive controls/buttons/pills/navbar, `--radius-card` (16px) for all surface containers/frames/cards/dialogs, and `--radius-inner` (10px) for nested content/images/codeblocks. Controls use 160ms feedback, hero and gallery view switches use 220 to 240ms transitions, dialogs enter at 220ms and exit at 140ms with matching backdrop timing. Fine-pointer hover lifts cards by 5px with vibrant glow drop shadows. Reduced motion disables intro, ambient travel, scroll entrances, and hover movement; dialogs and screenshot switches retain 100ms opacity. No animation dependency.

Icons & Composition Variety: icons communicate actual actions (download, theme, enlarge, source repository) and module/add-on subjects (dataset, pipeline, literature, plugin, integration, template, companion tool). External arrows distinguish links leaving the site; plus marks disclosure. Three primary-module panels represent the core research disciplines, the node editor receives its own asymmetric split section, Add-ons uses a 4-column category strip over an asymmetric verification/status panel, and the main repository section pairs action rows with a dual-repository distinction footer.

Team (`/tim`): names, roles, studio intro (`A Metriks Studio Production`), and Special Thanks (`UIN K.H. Abdurrahman Wahid Pekalongan`) sourced from `app/ui/data/credits.json` in `NezzyGremory/Data-Overview-Research-Assistant`. User explicitly authorized dummy details for biographies only. All draft biographies visibly display `Bio dummy`. Monograms are text, not fabricated photographs. No invented social profiles, achievements, or affiliations. Links to the repository direct visitors to the on-page `#github` section.

Add-ons Catalog (`#addons` & `src/config/addons.config.ts`): defines the four supported extension categories (`Plugin`, `Integrasi`, `Template`, `Perangkat pendamping`) and a strict 4-point verification contract. Public repositories of `NezzyGremory` and `AHTURRR` were audited on 2026-10-30; because no separate verified DORA add-on repository exists yet, `verifiedAddons` is empty and the UI renders an honest, informative empty state explaining what is already built into DORA (Kaggle/Hugging Face, OpenAlex/Scopus/SINTA/DOAJ, optional ML libraries) and how future add-ons are verified. No search/filter bar is rendered while the verified item count is zero.

Main Repository vs Website Repository (`#github`): clearly separates the core desktop application repository (`NezzyGremory/Data-Overview-Research-Assistant`, Python/PySide6, releases, issues, credits) from the optional Add-ons catalog and from this profiling website repository (`AHTURRR/Website-Profiling-DORA.`, React/TypeScript). Serves as the single comprehensive destination for all repository exploration, source code inspection, releases, and issue reporting.

Architecture & Release Metadata: two static React views at `/` and `/tim`, ordinary anchor navigation with browser-native history and Vercel rewrite support. Installer Center features 2 official versions: latest Version 7 (`v7.0.0`, `Data-Overview-Research-Assistant-v7-Setup.exe`, published 2026-10-30) and previous Version 6 archive (`v6.0.0`, `Data-Overview-Research-Assistant-v6-Setup.exe`, 95.1 MB, SHA256 `9cf4d44398aeb63afb863bcd5c431547d67441872f03dcda2f9344da6011f0c6`). Instant browser access is provided via DORA Web Beta (`https://data-overview-research-and-assistant.netlify.app`).

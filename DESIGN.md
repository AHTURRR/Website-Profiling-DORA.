# DORA website direction

Reference: Outcrowd, Website for an Incident Management Platform, https://dribbble.com/shots/26742281-Website-for-an-Incident-Management-Platform . Use its centered composition, generous space, near-black surfaces, violet accent, and authentic application preview as direction. All displayed product screenshots belong to DORA; do not reuse the reference product or its claims.

Identity: research software by Metriks Studio. Curious, precise, collaborative. Indonesian interface, short benefit-led headings, technical detail progressively disclosed. Pure product-first aesthetic without generic AI-slop sci-fi tropes.

ENERGY 2 / RHYTHM 2 / MOTION 2 (three-point scale). Centered hero with interactive four-view desktop window stage and five-step conceptual research flow; modular feature grid, visual pipeline topology, Add-ons empty/editorial state, and comprehensive repository sections; clean and human team grid on `/tim`. One typographic focal point per section. Both dark and light modes are intentionally crafted and stored in `dora-theme`.

Palette: dark uses near-black #08090d, surface #111218, text #f4f3f8, secondary #aaa9b8, violet #9e91ff, primary #6854df. Light uses paper #f7f6fb, white surface, text #22202e, secondary #5a5468, violet #5e3fb8, primary #6244ca. Violet identifies actions, active workflow steps, and section emphasis in both themes. Dark remains the default; the explicit user selection is stored under `dora-theme` and applied before styles load.

Hero & Product Stage: the hero centers a dominant HTML/CSS desktop window frame displaying real DORA screenshots (`overview.png`, `dataset-preview.png`, `node-editor.png`, `academic-research.png`). A centered showcase control cluster houses 4 numbered view tabs (`01 Overview`, `02 Dataset`, `03 Node Editor`, `04 Research`). The desktop frame features macOS-style traffic light window controls, app mark, version pill, active stage badge, and an expand button opening the full screenshot in a native `<dialog>`. Directly below the hero, a five-step conceptual workflow strip (`Memuat data` -> `Memahami data` -> `Merangkai eksperimen` -> `Menelusuri literatur` -> `Menyusun hasil`) is explicitly labeled as a conceptual illustration and synchronizes with the hero mockup views on click or tap.

Lighting & Surfaces: the hero ambient lighting scene uses a balanced, centered radial aura (`.hero-light`) positioned symmetrically behind the headline and window frame. The floating rounded navigation uses backdrop blur, preserving readability over scrolling content. No excessive glass cards or glowing icon soup.

Typography: retain Plus Jakarta Sans, whose rounded forms suit the DORA wordmark and human research context. JetBrains Mono is limited to filenames, commands, step indices, compatibility tags, and hashes. Headings use regular/medium weight, compact tracking, balanced lines. Body copy remains at least 14px.

Motion & Interactions: CSS ambient light drifts smoothly. The hero intro brings focus from headline to the product stage via clean staggered fade-up. In the Visual Node Editor section, an SVG pipeline topology banner renders the data and model pipeline flow between connected data and model nodes. The Preview section (`#preview`) features an authentic desktop screenshot showcase with category filtering, traffic-light window controls, and smooth thumbnail selector. All animations are hardware-accelerated (`transform`, `opacity`) and automatically disabled under `prefers-reduced-motion: reduce`. Content remains fully functional and accessible without JS.

Controls & Standardized Radius System: Floating navbar uses a unified 64px height with pixel-perfect vertical centering, pairing a direct DORA Web link (`https://data-overview-research-and-assistant.netlify.app`), ThemeToggle, and primary download CTA at an identical 40px height. External GitHub repository links are strictly consolidated into dedicated `#addons` and `#github` sections. Border radii strictly adhere to a 3-tier hierarchy: `--radius-pill` (9999px) for interactive controls/buttons/pills/navbar, `--radius-card` (16px) for surface containers/frames/cards/dialogs, and `--radius-inner` (10px) for nested content/images/codeblocks.

Team (`/tim`): names, roles, studio intro (`A Metriks Studio Production`), and Special Thanks (`UIN K.H. Abdurrahman Wahid Pekalongan`) sourced directly from `app/ui/data/credits.json` in `NezzyGremory/Data-Overview-Research-Assistant`. Official developer profile photographs provided by the team are integrated with clean discipline badges, responsive aspect ratio, and subtle hover interaction. Official jobdesk descriptions reflect each member's verified role and area of responsibility in the DORA project.

Add-ons Catalog (`#addons` & `src/config/addons.config.ts`): defines the four supported extension categories (`Plugin`, `Integrasi`, `Template`, `Perangkat pendamping`) and a strict 4-point verification contract. Public repositories of `NezzyGremory` and `AHTURRR` were audited; because no separate verified DORA add-on repository exists yet, `verifiedAddons` is empty and the UI renders an honest, informative empty state explaining what is already built into DORA (Kaggle/Hugging Face, OpenAlex/Scopus/SINTA/DOAJ, optional ML libraries) and how future add-ons are verified.

Main Repository vs Website Repository (`#github`): clearly separates the core desktop application repository (`NezzyGremory/Data-Overview-Research-Assistant`, Python/PySide6, releases, issues, credits) from the optional Add-ons catalog and from this profiling website repository (`AHTURRR/Website-Profiling-DORA.`, React/TypeScript). Serves as the single comprehensive destination for all repository exploration, source code inspection, releases, and issue reporting.

Architecture & Release Metadata: two static React views at `/` and `/tim`, ordinary anchor navigation with browser-native history and Vercel rewrite support. Installer Center features the single official release from GitHub (`v2.0.0`, `Data-Overview-Research-Assistant-v2.0.0-Setup.exe`, 95.1 MB, SHA256 `6004fe62f7ea2eaa7f9e350ac49c83e2b0aff5a4bb82c02beb10d62cf36b79e1`, published 2026-10-18, recompiled & updated 2026-11-01). Instant browser access is provided via DORA Web Beta (`https://data-overview-research-and-assistant.netlify.app`).
